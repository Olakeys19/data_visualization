Data Visualisation Projects

Charts and maps built with Python, Matplotlib and Pygal while working through Python Crash Course during my SIWES II training. Pygal charts are interactive: hover over bars and countries to see their values.

Matplotlib basics Random walks Rolling dice Weather data (CSV) World maps (JSON) Web APIs

Matplotlib basics

Line graphs and scatter plots with custom titles, labels, line widths and colormaps.

Random walks

A RandomWalk class generates a path where each step's direction and distance are chosen at random. The start point is green and the end point is red.

Rolling dice

A Die class simulates rolling dice thousands of times, and histograms show how often each result appears.

Weather data from CSV files

Daily temperatures read with the csv module and datetime, with missing values handled by exception handling.

World maps from JSON data

Population data loaded from a JSON file, matched to country codes, and drawn on interactive world maps.

Data from web APIs

The requests library calls the GitHub API, and the results are charted with clickable bars.
